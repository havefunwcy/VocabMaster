# VocabMaster (科学自适应背单词系统)

VocabMaster 是一款深度融合**认知心理学记忆理论**与**现代自适应间隔重复算法（FSRS 5.0）**的背单词系统。

---

## 🌟 核心认知科学特性与算法原理

1. **FSRS 5.0 记忆模型（DSR 状态评估）**
   - **Difficulty（难度 1-10）**：根据初次学习与后续复习的历史评级自适应修正；
   - **Stability（稳定性/存续天数）**：量化记忆在大脑中能够留存的时长；
   - **Retrievability（提取概率 0-1）**：精确预测当前时刻的遗忘概率并在最佳临界点推送复习。

2. **主动回忆（Active Recall）与生成效应**
   - 绝非被动浏览释义，先想后看；
   - 支持**形近词智能辨析**（利用 Levenshtein 距离与同词性/首字母生成高迷惑性干扰项）。

3. **神经提取延迟加权（Reaction Latency Penalty）**
   - 毫秒级追踪用户作答耗时；
   - 若出现犹豫或提取困难（> 4.2秒），即使点击“掌握”，系统也会自动对稳定性增幅施加阻尼，避免“流畅度错觉”。

4. **防疲劳交错队列（Interleaving Optimization）**
   - 动态混合新词与复习词（2:1 黄金交错比）；
   - 实时监测连续错误率与延迟增幅，提供认知负荷预警与休息建议。

5. **词库与短语生态 (Deck & Phrase Management)**
   - 📌 **专属短语/搭配库**：内置《考研/四六级必背高频短语》、《雅思学术写作地道表达与习语》，适配多词语音、语境挖空与空格拼写；
   - ➕ **单条添加短语/词条**：智能识别空格自动标记为短语，支持中文释义、词性、真实例句及记忆助记；
   - 📁 **新建专属词库**：支持创建自定义专属词库/短语集，定制主题配色与归属分类；
   - 📤 **灵活批量导入/导出**：按行或 JSON 极速导入，一键导出完整复习进度备份。

6. **四大维度全方位强化训练**
   - 🎴 **闪卡主动回忆 (Flashcard)**：深思提取、固定短语标识、词根词缀、科学助记；
   - 📝 **语境填空 (Context Cloze)**：真实例句挖空，短语多词首字母提示（如 `t___ i___ a______`）；
   - ✍️ **听写拼写 (Spelling Quiz)**：听音辨意，支持短语空格连续拼写，强化听觉反射与拼写；
   - ⚡ **极限速刷 (Speed Run)**：高稳定性单词/短语快速过筛与多倍连击激励。

7. **全维度记忆画像 (Analytics Dashboard)**
   - 稳定性漏斗分布（新词 $\rightarrow$ 晃荡期 $\rightarrow$ 强化期 $\rightarrow$ 稳固期 $\rightarrow$ 永久记忆）；
   - 艾宾浩斯留存曲线预测对比。

## 🚀 启动与运行

在项目目录下执行：

```bash
# 启动本地开发服务
npm run dev
```

浏览器打开 `http://localhost:5173` 即可开始科学背单词！

## ⌨️ 键盘盲打快捷键

| 按键 | 功能说明 |
| :--- | :--- |
| `Space` (空格) | 翻转卡片 / 查看释义 |
| `1` | 评级：**忘记 (Again)**（10分钟后重现） |
| `2` | 评级：**困难 (Hard)** |
| `3` | 评级：**掌握 (Good)** |
| `4` | 评级：**秒杀 (Easy)** |
| `R` | 重新播放真人发音 |
| `S` | 快速收藏到生词本 |
